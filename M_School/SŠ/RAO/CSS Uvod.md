### Sestavni deli/Sintaxa
![[Pasted image 20251122182441.png]]
- Selektor kaže na HTML element, ki ga želimo oblikovati. 
- Blok deklaracij vsebuje eno ali več deklaracij, ločenih s podpičji.
- Vsaka deklaracija vključuje ime lastnosti CSS in vrednost, ločeni z dvopičjem. 
- Več CSS deklaracij je ločenih s podpičji, bloki deklaracij pa so obdani z zavitimi oklepaji.
