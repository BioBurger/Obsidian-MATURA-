- Je za dodajanje layer-jev v spletno stran
```css
/* Keyword value */
z-index: auto;/*isto kot 0*/

/* <integer> values */
z-index: 0;/*default*/
z-index: 3;/*nad vsem kar je manjže*/
z-index: 289;/*nad vsem kar je manjže*/
z-index: -1; /* Negative values to lower the priority */

/* Global values */
z-index: inherit;
z-index: initial;
z-index: revert;
z-index: revert-layer;
z-index: unset;
```
