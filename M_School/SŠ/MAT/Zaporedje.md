$$f: \mathbb{N} \to \mathbb{R}$$ $$n \to a_{n}$$ $$a_{1},a_{2},....,a_{n}$$ $$a_{n} \to \text{ je splošni člen.}$$ $$\text{Graf zaporedja je množica urejenih parov }(1, a_{1}), (2, a_{2}),...$$ 
## Lasnosti:
### Naraščajoče zaporedje $$\text{Če za vsako }\mathbb{N}\text{-število velja }a_{m+1}\geq a_{m}$$
### Padajoče zaporedje 
$$\text{Če za vsako }\mathbb{N}\text{-število velja }a_{m+1}\leq a_{m}$$
### Omejenost 
$$m\leq a_{m} \leq M$$
#### Primer:
$$a_{n}=\frac{n}{n+1} \text{ kjer } m=0,\ M=1$$ $$\begin{aligned} &\text{Spodnja meja } m:\\ &\frac{n}{n+1}\geq 0 \Rightarrow n\geq0 \checkmark \end{aligned}$$ $$\begin{aligned} &\text{Zgornja meja } M:\\ &\frac{n}{n+1}\leq 1 \Rightarrow n\leq n+1 \Rightarrow 0\leq 1 \checkmark \end{aligned}$$ 
## Limita zaporedja 
$$\lim_{n\to\infty} a_n = L \quad \text{(zaporedje konvergira k } L\text{)}$$ $$\text{Če limita ne obstaja ali je } \pm\infty\text{, zaporedje divergira.}$$
